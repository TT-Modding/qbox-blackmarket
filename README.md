# qbox-blackmarket
Black Market Selling Script for Qbox using ox_lib and ox_target (swedish)



"Swedish":

Jag rekomenderar denna script för svenska servrar om man inte vill ändra till ett annat språk själv.

Sälj inte denna script eller redistributera denna script. Konfigurera scripten lätt i config.lua filen. Ändra modell, plats och vilka items man kan sälja till black market. Tack.


"English":

I recommend this script for Swedish servers if you don't want to change the script to another language yourself.

Do not sell this script or redistribute this script. Configure the script easily in the config.lua file. Change the model, location and which items can be sold to the black market. Thank You.
Also you can change the lines to english in client.lua.
